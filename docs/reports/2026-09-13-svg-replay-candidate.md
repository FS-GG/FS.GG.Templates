# SVG replay generated-candidate qualification

The optional generated Studio composes `FS.GG.Game.Core` replay, planning, and rule-catalog contracts from
Game commit `69c99ff34cd0b84516589796e7163f510de3d49a`. Four native, labelled and focusable surfaces provide a
timeline, first-divergence inspector, scenario planner, and dependency-ordered rule explorer. The neutral
counter and energy examples call the real package APIs; the template does not implement a second replay or
planning transition system.

The exact-candidate workflow packs Game from that merged revision, packs Templates from the pull-request head,
installs a clean generated workspace, and exercises every control by keyboard in Chromium, Firefox, and WebKit.
It checks record/replay, checkpoint seek, cancellation cursors, deliberate divergence, accepted/predicted and
authored separation, scenario cancellation, ordered explanations, and filtering of a server-only cause.

The same receiver runs installed `FS.GG.SDD.Cli` 1.7.0 with backend `quint-specification-v1`, profile
`fsgg-quint-profile/2`, and digest-qualified Quint 0.32.0/lmt objects. Author and inspect materialize guidance
from the shipped neutral model and selector. A copied receiver then changes the authored source and must be
refused by inspect, proving the generated view cannot silently remain current after source drift.

The production Player is built separately from public Release-B pins. Its emitted files are scanned for the
Studio module, replay controls, planner, and rule explorer, establishing that these optional analysis tools do
not enter the Player bundle. Candidate and qualification JSON preserve the exact Game package, Templates
source, installed package, browser observations, backend/profile, and unpublished status.
