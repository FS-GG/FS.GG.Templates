# Polyglot CLI display name

This typescript CLI keeps display, package and code identities separate. The creator must supply a valid ecosystem package identity and code identifier.

Run the closed operations through `sh scripts/operations.sh build`, `lint`, `test`, `public-surface`, `package`, `security`, `evidence` and `release`. These executable scripts own commands and refusal behavior. Security refuses until its exact scanner/advisory closure is selected and qualified.

Product files own no `.fsgg` lifecycle tree. Use the published catalog scaffold route to compose the single Quint lifecycle, process skills and revision-bound provenance. Generated-source and ordinary payload checks alone do not certify installed Governance, security or OS support.
