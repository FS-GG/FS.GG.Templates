# Current-reference native input source contract

The maintained current-public full AT route includes native Pinyin commit/cancel
and a German dead-key journey against the generated `input#fourd-reference-note`
(`Encounter note`). `CURRENT_PUBLIC_AT_ADMISSION` remains `None`. Source delivery,
inert controls and a supplied manifest grant no desktop operation or acceptance.
Historical and font-disposal routes retain their selections.

The authenticated reusable callee accepts `native-input-facility` JSON through its
existing caller. An empty input remains empty. Full mode refuses a missing or
malformed tuple before package acquisition or tool execution, after the owning
admission guard. Preflight-only mode may bind a supplied tuple without executing it.
The exact helper digest, canonical manifest digest, controller, public Template
archive, typed plan and original Rendering custody stay separate bound identities.
Rendering must adopt the delivered controller pin and manifest in the same owner
chain; an older caller does not acquire this contract automatically.

## Required facility inputs

`current-reference-native-input.py` owns the closed schema. Its required fields are:

| Field | Required original inputs |
| --- | --- |
| `schema`, `platform` | `fsgg.current-reference-native-input-facility/1`, `ubuntu-24.04-x11` |
| `packages` | Nonempty exact installed names/versions, original Debian archive hashes and source URI/hash tuples, including the selected Ubuntu patch levels |
| `objects` | Exact package-owned paths and SHA256 for `ibusDaemon`, `ibusConfig`, `dconfService`, `pinyinEngine`, `simpleEngine`, `gtk3`, `ibusGtk3`, `setxkbmap`, `xkbcomp`, `xdotool`, `dpkgQuery` |
| `dataFiles` | Exact package-owned dictionary, XKB, schema and one Compose table path/hash; no ambient user Compose file |
| `keymaps` | Exact compiled private-display US and German keymap hashes |

Missing pins have no defaults. Runtime verifies installed versions, package file
ownership, immutable file bytes and actual GTK3/IBus client mappings. Package and
source archive hashes identify the reviewed supplier tuple; local file/version
readback does not authenticate those archives or establish how each data file was
read. Original facility acquisition and full dependency qualification remain owed.

## Actual native route and limits

The existing owned launcher registers foreground IBus, dconf, IBus config,
libpinyin and simple-engine births in the original session. It uses private
HOME/config/data/cache, a private IBus address, pinned Compose data, disabled cloud
input, explicit Chromium X11/GTK3 flags and the existing finite work/cleanup budget.
It neither replaces ambient services nor uses desktop activation or automatic
restart. Unexpected daemon-spawned components refuse. All actors remain in the
existing census/retirement route; the sampled observer adds no hard containment
claim and retains its detached-descendant limits.

Native Tab navigation and AT-SPI identify the real textbox. XTest keys type
`nihao`, Space commits `你好`, a second preedit is cancelled with Escape, and the
selected German XKB map delivers existing `dead_acute` then `e` to produce `é`.
Capture-only hooks retain trusted composition/input/key/focus observations.
Original key order, text, phase continuity, focus, unchanged gameplay command order
and cell, and unchanged compiled keymap are checked. No DOM dispatch/fill or direct
Unicode/IME commit actuation substitutes for this route. Save/replay/disposal then
use the existing journey, including removal from the AT tree.

IBus unique-name appearance after an exact foreground executable birth is recorded
as a **causal association**, not authenticated bus-connection-to-PID attribution.
The [upstream IBus dispatcher](https://github.com/ibus/ibus/blob/1.5.29/bus/dbusimpl.c)
declares but does not implement the ordinary D-Bus PID method. The selected package patch level remains a supplier pin; unsupported
attribution is not promoted. The separate ordinary private session bus supplies
the actual dconf PID join. Unknown ownership, containment or retirement cannot be
cleared by the scoped native-input observation.
